# ☕ Primeiro Projeto Java

Repositório de estudos em Java, contendo exercícios práticos desenvolvidos durante o aprendizado da linguagem.

---

## 📁 Estrutura do Projeto

```
src/
├── ConvertCtoF/
│   └── ConvertCtoF.java       # Conversor de Celsius para Fahrenheit
├── MoedaConvert/
│   └── MoedaConvert.java      # Conversor de Real para Euro
├── teste/
│   ├── CatalogoFilme.java     # Catálogo de filmes
│   └── Estudo.java            # Exercícios gerais
└── Main.java                  # Classe principal
```

---

## 🚀 Tecnologias

- Java 17+
- IntelliJ IDEA

---

## 📚 Conceitos Praticados

- Classes e objetos
- Construtores
- Modificadores de acesso (`public`, `private`)
- Métodos estáticos e de instância
- Conversão de tipos (`casting`)
- `BigDecimal` para precisão decimal

---

## ▶️ Como Executar

1. Clone o repositório
```bash
git clone https://github.com/Icaro-Vieira-dev/primeiro_projeto_java.git
```

2. Abra no IntelliJ IDEA

3. Execute a classe `Main.java`
